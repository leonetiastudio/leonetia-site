# LEONETIA Estudio Creativo

Sitio institucional inicial para `leonetia.com`.

## Contenido

- Identidad visual base.
- Logo aprobado en PNG.
- Imagen hero generada para la primera pantalla.
- Home estatica lista para GitHub Pages.
- Cotizador editable en `cotizador.html`.
- Guia de marca en `brand-guidelines.md`.

## Publicacion En GitHub Pages

Repositorio previsto: `leonetiastudio/leonetia-site`.

Configuracion recomendada en GitHub:

- Settings -> Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

URL temporal esperada:

`https://leonetiastudio.github.io/leonetia-site/`

Despues se conecta el dominio:

`leonetia.com`
